# 🎮 Backlogd

Projeto acadêmico desenvolvido com Django inspirado em plataformas como Backloggd e Letterboxd, permitindo que usuários organizem, avaliem e acompanhem seus jogos em um backlog pessoal.

O sistema possui integração com a RAWG API para busca automática de jogos, imagens e descrições, além de autenticação de usuários e interface moderna utilizando TailwindCSS.

---

# 📚 Objetivo Acadêmico

O projeto foi desenvolvido com fins de estudo e prática dos principais conceitos de desenvolvimento web utilizando Django.

Durante o desenvolvimento foram aplicados conceitos como:

- CRUD completo;
- autenticação de usuários;
- integração com APIs externas;
- manipulação de banco de dados;
- templates Django;
- organização MVC;
- estilização moderna com TailwindCSS;
- relacionamento entre tabelas;
- proteção de rotas.
